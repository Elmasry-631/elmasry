# Sale Order Barcode Scanner

- **المسار والإصدار:** `odoo18/sale_barcode_scanner` — Odoo 18
- **إصدار الحزمة:** `18.0.1.0.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Scan products by Barcode/QRCode in sales orders using mobile camera or webcam

## الغرض والنطاق

Scan products by Barcode/QRCode in sales orders using mobile camera or webcam

هذا الوصف مرتبط بملفات الموديول في هذه النسخة. يتضمن المصدر 4 ملف Python و2 ملف XML و2 ملف JavaScript/TypeScript.

## ملفات التثبيت

`sale_management`, `product`, `barcodes`

راجع [FEATURES.md](FEATURES.md) للوظائف المكتشفة و[INSTALLATION.md](INSTALLATION.md) للتثبيت الخاص بإصدار Odoo 18.
