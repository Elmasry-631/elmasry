# Investment Clubs Management

- **المسار والإصدار:** `odoo18/investment_club` — Odoo 18
- **إصدار الحزمة:** `18.0.12.0.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Complete investment management system with Unified Return System

## الاختبارات المرفقة

- لا يحتوي الموديول على مجلد `tests/`؛ لذلك لا توجد اختبارات Odoo مرفقة.

## تشغيل اختبارات Odoo

`./odoo-bin -d <test_database> -i investment_club --test-enable --stop-after-init`

## فحوص المصدر

- تحقق من أن ملفات Python قابلة للتحليل وأن XML صالح.
- اختبر التثبيت على Odoo 18 مع dependencies والطبعة نفسها.
- لا تعتبر وجود ملفات tests دليلًا على نجاح تشغيلها؛ سجل النتيجة والبيئة عند التنفيذ.
