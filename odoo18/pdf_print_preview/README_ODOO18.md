# تحديث موديول Pdf Print Preview ليعمل على أودو 18

تم إجراء التعديلات التالية لضمان توافق الموديول مع الإصدار 18 من أودو:

## 1. تحديث ملف Manifest
- تحديث الإصدار إلى `18.0.1.0.0`.
- نقل تعريفات ملفات الـ XML الخاصة بالقوالب (Templates) من ملف `assets.xml` القديم إلى قسم `assets` في ملف `__manifest__.py`.
- إزالة ملف `assets.xml` لأنه لم يعد مستخدماً في أودو 18 لتعريف الأصول.

## 2. تحديث ملفات JavaScript (OWL & Web Framework)
- **pdf_preview.js**: 
    - تحديث الاستيرادات لتستخدم `@web` بدلاً من المسارات القديمة.
    - استبدال `web.rpc` بخدمة `rpc` الحديثة من `env.services`.
    - تحديث استيراد `session` من `@web/session`.
- **dialog.js**:
    - تحديث المكون ليتوافق مع نظام الحوارات (Dialog Service) في أودو 18.
    - إضافة `props` لتعريف المدخلات بشكل صحيح.
    - استخدام `registry.category("services").get("dialog").add` لفتح النافذة المنبثقة.
- **user_menu.js**:
    - تحديث استدعاء الـ RPC ليتوافق مع الصيغة الجديدة.

## 3. تحديث ملفات Python (Backend)
- **ir_actions_report.py**: تحديث توقيع الدالة `_render_qweb_pdf` لإضافة `**kwargs` لضمان التوافق مع التغييرات في أودو 18.
- **ir_http.py**: تحديث دالة `session_info` لتتوافق مع الهيكل الجديد وتجنب الأخطاء عند عدم وجود مستخدم.
- **res_users.py**: تحديث الدوال `_get_self_readable_fields` و `_get_self_writeable_fields` لتستخدم الصيغة الحديثة (Set) بدلاً من القوائم القديمة.
- **main.py**: إصلاح استيرادات `werkzeug` وتحديث معالجة البيانات القادمة من الطلبات.

## 4. تحديث ملفات XML (Views & Templates)
- **dialog.xml**: تحديث القالب ليتوافق مع مكون `Dialog` الحديث وإضافة زر الإغلاق في الـ `footer`.
- **res_users.xml**: 
    - تحديث مكان ظهور صفحة الإعدادات لتكون بعد صفحة "Preferences".
    - تحسين تصميم نافذة الإعدادات السريعة وإضافة مفاتيح الاختصار (Hotkeys).
