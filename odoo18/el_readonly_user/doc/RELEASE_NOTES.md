# Release Notes

## 18.0.1.1.0

- Renamed the module technical name to `el_readonly_user`.
- Exposed the readonly group in the standard user Access Rights section.
- Hid Configuration/Settings menus for readonly users.
- Hid stock movement menus and blocked readonly access to stock movement data.
- Updated module ownership and metadata to Ibrahim Elmasry.


## 18.0.1.2.0

- Restored readonly read access to warehouses, inventory, and stock movements.
- Removed stock movement menu/model hiding.
- Preserved readonly protection against create, write, delete, and stock-operation execution.
- Kept Configuration and Settings menus hidden for readonly users.
