EL Readonly User Access

Author: Ibrahim Elmasry

Controlled read-only access for selected Odoo users.

Security behavior

  • Readonly users cannot create, modify, or delete normal business records.
  • The access group is available in the standard Users > Access Rights section.
  • Configuration and Settings menus are hidden for readonly users.
  • Inventory and stock movement data remain visible, while stock modifications are blocked for readonly users.
  • Odoo core files are not modified.
