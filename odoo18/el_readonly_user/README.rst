EL Readonly User Access
=======================

EL Readonly User Access provides controlled read-only access for selected Odoo users.

Features
========
* Read-only access without create, write, or delete operations.
* Readonly group available in the standard ``res.users`` Access Rights section.
* Configuration and Settings menus are hidden for readonly users.
* Inventory, warehouse, and stock movement data remain readable for readonly users.
* Stock movement records remain protected from create, write, delete, and operation execution.
* No Odoo core files are modified.
