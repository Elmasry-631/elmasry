# مطابقة رصيد العميل — Balance Confirmation

<p align="center">
  <img src="static/icon.png" alt="Balance Confirmation" width="120"/>
</p>

موديول Odoo 19 لطباعة وتصدير وإرسال "مطابقة رصيد العميل" بقالبين احترافيين مطابقين تماماً لملفات Word الأصلية.

---

## ✨ المزايا

| الميزة | الوصف |
|--------|-------|
| 🖨️ **طباعة PDF** | PDF مطابق 100% لقالب Word الأصلي (نفس الخطوط، الأختام، الشعارات) |
| 📝 **تصدير Word** | ملف Word (.docx) بنفس قالب الأصل مع تعبئة الحقول تلقائياً |
| 📧 **إرسال بالإيميل** | إرسال المطابقة للعميل مباشرة من الويزارد (يدعم العربية والإنجليزية) |
| 🤖 **تعبئة تلقائية** | التاريخ، اسم العميل، الرصيد، اسم الموظف |
| 🔢 **تفقيط عربي** | تحويل الرقم إلى نص عربي صحيح نحوياً (ريال/ريالاً، هللة/هللة) |
| 🎯 **قالبان** | قالب امداد وقالب نمو - بنفس شكل الأصل بالظبط |
| 🌐 **ثنائي اللغة** | الواجهة تظهر بالعربية أو الإنجليزية حسب لغة المستخدم |
| ✅ **قواعد الأقواس** | الرصيد فقط يظهر بين قوسين `( 1234.56 )`، باقي الحقول بدون أقواس |

---

## 📦 المتطلبات

### أساسية (موجودة افتراضياً)
- **lxml** — مكتبة XML (تأتي مع Odoo 19)
- لا توجد مكتبات Python إضافية مطلوبة

### اختيارية (لتحويل Word → PDF بجودة عالية)

| البرنامج | المنصة | أهمية |
|----------|--------|-------|
| **Microsoft Word** + pywin32 | Windows فقط | ⭐ الأفضل — تطابق 100% |
| **LibreOffice** | Windows / Linux / Mac | ممتاز — تطابق 99%+ |

> 💡 **ملاحظة**: الموديول يعمل بدون أي من البرنامجين، لكنه يستخدم قالب QWeb بديل في تلك الحالة (لن يكون مطابقاً 100% لقالب Word).

### تثبيت LibreOffice (بديل مجاني)

#### على Windows:
1. حمّل LibreOffice من https://www.libreoffice.org/download/
2. ثبّته في المسار الافتراضي
3. الموديول سيجده تلقائياً في:
   - `C:\Program Files\LibreOffice\program\soffice.exe`

#### على Linux:
```bash
sudo apt install libreoffice      # Debian/Ubuntu
sudo yum install libreoffice      # RHEL/CentOS
```

### تثبيت MS Word + pywin32 (الأفضل على Windows)
```bash
pip install pywin32
```
> يجب تثبيت MS Office (Word) على نفس جهاز Odoo.

## 🚀 التثبيت

1. انسخ مجلد `partner_balance_confirmation` إلى مجلد `addons` في Odoo
2. أعد تشغيل خدمة Odoo:
   ```bash
   sudo systemctl restart odoo
   ```
3. من قائمة **Apps** في Odoo:
   - اضغط **Update Apps List**
   - ابحث عن "Balance Confirmation" أو "مطابقة رصيد العميل"
   - اضغط **Install**

## 📖 الاستخدام خطوة بخطوة

### 1. فتح شاشة العميل
- اذهب إلى **Contacts** (جهات الاتصال)
- افتح بطاقة العميل المطلوب

### 2. فتح الويزارد
- اضغط زرار **"Print Confirmation"** (أو **"طباعة المطابقة"**) في أعلى البطاقة

### 3. اختيار البيانات
في نافذة الويزارد ستجد:
- **Customer**: اسم العميل (تلقائي)
- **Confirmation Date**: تاريخ المطابقة (افتراضي = اليوم)
- **Template**: اختيار القالب
  - **Imdad** (امداد)
  - **Namo** (نمو)
- **Printed By**: اسم الموظف (تلقائي = المستخدم الحالي)
- **Balance**: الرصيد حتى تاريخ المطابقة (محسوب تلقائياً)
- **Balance in Words**: الرصيد كتابةً بالعربية
- **Additional Notes**: ملاحظات إضافية تظهر في التقرير

### 4. اختيار الإجراء
| الزر | الوظيفة |
|------|---------|
| **Print PDF** | تحميل PDF مطابق 100% لقالب Word |
| **Export Word** | تحميل ملف Word (.docx) معبأ بالبيانات |
| **Send by Email** | إرسال PDF بالإيميل للعميل |

## 🔧 كيف يعمل الموديول

```
[قالب Word الأصلي (.docx)]
       │
       ▼
[XML-level placeholder replacement — lxml]
   • الحقول الحمراء (#EE0000) تُستبدل بالقيم الفعلية
   • الصور، الأختام، الشعارات محفوظة 100%
   • اللون الأحمر يتحول إلى أسود
   • الأقواس تُحذف لكل الحقول ما عدا الرصيد
       │
       ├──→ [ملف Word ممتلئ (.docx)]  ← تصدير Word
       │
       ▼
[تحويل إلى PDF]
   ├──→ [MS Word COM] ← Windows + MS Word (الأفضل)
   ├──→ [LibreOffice headless] ← أي نظام
   └──→ [QWeb fallback] ← إذا لم يتوفر أي منهما
       │
       ▼
[ملف PDF مطابق للأصل]  ← تصدير PDF / إرسال بالإيميل
```

## 🎨 قوالب Word المدعومة

| القالب | الملف | الوصف |
|--------|------|-------|
| **امداد** (Imdad) | `data/template_amdad.docx` | قالب شركة امداد |
| **نمو** (Namo) | `data/template_namo.docx` | قالب شركة نمو المتقدمة |

كل قالب يحتوي على:
- شعار الشركة في الرأس
- علامة مائية (watermark) في الخلفية
- ختم/شعار في الأسفل
- حقول حمراء يتم تعبئتها تلقائياً

## 🌐 ثنائي اللغة

- الواجهة (القوائم، الأزرار، الرسائل) تتبع لغة المستخدم
- قالب البريد الإلكتروني يتبع لغة العميل:
  - إذا كانت لغة العميل تبدأ بـ `ar` → البريد بالعربية (RTL)
  - غير ذلك → البريد بالإنجليزية (LTR)

## 🛠️ حل المشاكل

### المشكلة: PDF لا يطابق Word 100%
**الحل**: تأكد من تثبيت أحد:
- MS Word + pywin32 (Windows) — الأفضل
- LibreOffice (أي نظام)

### المشكلة: خطأ "bootstrap.ini is corrupt" (LibreOffice على Windows)
**الحل**:
1. احذف مجلد `%APPDATA%\LibreOffice`
2. أصلح LibreOffice من Control Panel
3. أو ثبّت MS Word + pywin32 (يأخذ الأولوية تلقائياً)

### المشكلة: الاختام لا تظهر في PDF
**الحل**: تأكد أنك تستخدم الإصدار 19.0.3.0+ من الموديول (الإصدارات القديمة كانت تستخدم python-docx الذي يحذف الصور).
