Al Rajhi Bank (ARB) Payment Gateway for Odoo بوابة دفع مصرف الراجحي لنظام أودو

Overview

English Overview

This module connects Odoo with Al Rajhi Bank through a secure bank-hosted payment flow. It helps merchants install the provider, configure credentials, test safely, publish when ready, and offer Al Rajhi payment selection to website customers.

نظرة عامة بالعربية

تقوم هذه الوحدة بربط أودو مع مصرف الراجحي من خلال صفحة دفع آمنة مستضافة من البنك. وهي تساعد التاجر على تثبيت المزود وإعداد البيانات واختبار التكامل ثم نشره وإتاحته للعملاء في المتجر الإلكتروني.

Important Notes

English Notes

Bank credentials are mandatory. Make sure you already received the correct Tranportal ID, Tranportal Password, and Resource Key from Al Rajhi Bank.

Use the correct environment. Keep the UAT endpoint for test mode and the production endpoint for live mode.

Public URL matters. Set web.base.url to a valid public HTTPS URL for clean callback handling.

ملاحظات بالعربية

بيانات البنك مطلوبة. تأكد من حصولك على Tranportal ID وTranportal Password وResource Key الصحيحة من مصرف الراجحي.

استخدم البيئة الصحيحة. استخدم رابط UAT في وضع الاختبار واستخدم رابط الإنتاج عند التشغيل الفعلي.

الرابط العام مهم. اضبط web.base.url على رابط HTTPS عام وصحيح حتى تعمل روابط العودة بشكل سليم.
