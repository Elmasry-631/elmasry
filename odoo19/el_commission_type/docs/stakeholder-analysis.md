# Stakeholder Analysis - el_commission_type

## Stakeholders

| Role | Access Level | Description |
|------|--------------|-------------|
| Administrator | Full Access | Can create, edit, delete commission types |
| Sales Manager | Read/Write | Can view and modify commission types |
| Sales User | Read Only | Can only view commission types |

## Security Groups

### Group: Commission Type User
- Access Mode: Read
- Users: Sales team members

### Group: Commission Type Manager  
- Access Mode: Write
- Users: Sales managers, administrators
