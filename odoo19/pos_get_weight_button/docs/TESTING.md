# POS Get Weight Button

- **المسار والإصدار:** `odoo19/pos_get_weight_button` — Odoo 19
- **إصدار الحزمة:** `1.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Adds a Get Weight button to POS control buttons

## الاختبارات المرفقة

- لا يحتوي الموديول على مجلد `tests/`؛ لذلك لا توجد اختبارات Odoo مرفقة.

## تشغيل اختبارات Odoo

`./odoo-bin -d <test_database> -i pos_get_weight_button --test-enable --stop-after-init`
