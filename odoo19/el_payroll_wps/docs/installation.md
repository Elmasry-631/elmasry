# Installation Guide — el_payroll_wps

## Prerequisites
- Odoo 19.0+ (Community or Enterprise)
- `hr_payroll` module installed
- (Soft) `hr_work_entry_enterprise` installed — provides the Payroll root menu xmlid used as the menu parent. If not installed, the `post_init_hook` reparents the menu by name lookup.
- Python 3.10+ (ships with Odoo 19)

## Step-by-step Installation

### 1. Copy the module into your addons directory
```bash
cp -r el_payroll_wps /opt/odoo/addons/
chown -R odoo:odoo /opt/odoo/addons/el_payroll_wps
```

### 2. Restart Odoo
```bash
sudo systemctl restart odoo
```

### 3. Update Apps List
1. Log in as Administrator.
2. Enable Developer Mode.
3. **Apps** → **Update Apps List** → confirm.

### 4. Install the module
1. In **Apps**, clear the "Apps" filter.
2. Search for `Payroll WPS Export`.
3. Click **Install**.

### 5. Verify installation
- Go to **Payroll** app.
- You should see **WPS Export** menu item (sequence 100).
- Open any payslip → after `note`, you should see the `Others` field.

## Post-installation: `post_init_hook`
At install time, `el_payroll_wps/__init__.py::post_init_hook` runs and:
1. Looks up `ir.ui.menu` where `parent_id = False` and `name = 'Payroll'`.
2. If the static `parent="hr_work_entry_enterprise.menu_hr_payroll_root"` already worked, this is a no-op.
3. If the xmlid is missing (custom build), it reparents `menu_wps_export` under the found Payroll root menu.

## Upgrade
```bash
sudo systemctl stop odoo
odoo -c /etc/odoo/odoo.conf -d <db_name> -u el_payroll_wps --stop-after-init
sudo systemctl start odoo
```

## Uninstall
1. **Apps** → Payroll WPS Export → ⋮ → Uninstall.
2. Removed automatically:
   - `x_others` column from `hr_payslip`
   - `wps_export_wizard` table
   - `menu_wps_export`, `action_wps_export_wizard` records
   - ACL entries
3. NOT removed (owned by `ir.attachment`):
   - Any CSV files generated by past exports

## Docker Compose
```yaml
services:
  odoo:
    volumes:
      - ./addons/el_payroll_wps:/mnt/extra-addons/el_payroll_wps
```
Restart container and follow Step 3 onwards.
