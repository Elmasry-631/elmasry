# Icon Design — el_payroll_wps

## 1. Design Brief
- **Module name:** el_payroll_wps
- **Primary purpose:** Monthly salary CSV export for bank submission (WPS), with an auto-computed "Others" field on payslips.
- **Odoo category:** Human Resources/Payroll → color family: HR red/purple (`#8B5A8C` family, matching the standard `hr_payroll` icon).

## 2. Visual Concept
The icon was generated by AI to convey "payroll people + money + bank submission" in a single 3D-rendered mark:
- A small group of stylized human figures (the workforce whose wages are being protected).
- A subtle bank-card / banknote motif (the CSV destination: the bank).
- Soft red/purple HR palette so it visually clusters with the other Payroll app icons in the Odoo app drawer.

## 3. Style Choices
- **Style:** 3D render (matches the modern Odoo 17+/18+/19 icon aesthetic).
- **Composition:** centered, square, soft lighting, depth of field.
- **No text / no letters** — per Odoo icon guidelines, the glyph must read at 32×32 px; text would be illegible.
- **Background:** clean, single-tone — so the icon "pops" against both light and dark Odoo themes.

## 4. Technical Specs
- **Size:** 256×256 px (Odoo's required icon size).
- **File size:** ~55 KB (well under the 100 KB budget, above the 5 KB minimum).
- **Format:** PNG with alpha.
- **Path:** `static/description/icon.png`.

## 5. Rationale
A red/purple HR-family icon instantly tells the user "this lives under Payroll". The people motif signals "wages", the bank-card motif signals "submission to bank", and the 3D style matches the rest of the modern Odoo icon set.

## 6. Note on Icon Regeneration
The user's original upload contained a 3 KB icon — below the skill's 5 KB minimum. The icon was regenerated using the skill's `generate_ai_icon.py` script (3D style, HR category, red theme). The regenerated icon is 55 KB and meets all skill requirements.
