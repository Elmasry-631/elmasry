# POS Daily Sequence

- **المسار والإصدار:** `odoo19/pos_daily_sequence` — Odoo 19
- **إصدار الحزمة:** `19.0.1.0.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Automatically reset POS order numbering every day

## الغرض والنطاق

Automatically reset POS order numbering every day

هذا الوصف مرتبط بملفات الموديول في هذه النسخة. يتضمن المصدر 6 ملف Python و3 ملف XML و1 ملف JavaScript/TypeScript.

## ملفات التثبيت

`point_of_sale`, `mail`, `stock`, `account`
