# Construction Management Reporting — V20 Premium Redesign

Module: Construction Management
Module Version: 19.0.1.10.0

## Scope

A complete visual and information redesign of the 17 construction PDF reports. The redesign introduces a unified Construction Management reporting identity, executive KPI blocks, status badges, progress indicators, detailed operational/commercial tables, certification sections, notes/callouts, and portrait/landscape paper formats.

2. Sub Project Report

17. Timesheet Report

## Validation boundary

Static validation is performed on XML syntax, Python syntax, report action/template mapping, external IDs, and referenced model fields. Runtime PDF rendering still requires installation/upgrade on an Odoo 19 instance with the module dependencies available.
