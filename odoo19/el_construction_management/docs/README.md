# Construction Management Documentation

This documentation set is the functional and technical reference for the Construction Management module for Odoo 19.

## Documents

- [User Guide](USER_GUIDE.md) — complete end-to-end operating procedures.
- [Administration Guide](ADMIN_GUIDE.md) — installation, configuration, security, upgrade, and troubleshooting.
- [Functional Workflows](WORKFLOWS.md) — lifecycle and state transitions.
- [Inventory & Material Control](INVENTORY.md) — Odoo Inventory integration and site material flow.
- [Reporting](REPORTING.md) — report center and reporting procedures.
- [Architecture](ARCHITECTURE.md) — technical architecture, model boundaries, extension strategy, and data flow.
- [Security](SECURITY.md) — access-control model and governance.
- [Migration](MIGRATION.md) — upgrade and migration notes.

## Documentation principles

The documentation is organized around user journeys rather than source-code files. The module uses Odoo standard objects where possible and keeps Odoo Inventory as the inventory source of truth.
