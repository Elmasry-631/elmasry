# Functional Workflows

## Project lifecycle
Project → Sub Project → WBS/Phases → Tasks/Work Orders → Progress/Cost → Quality → Commercial Closeout → Project Close.

## Procurement/material lifecycle
Material Requisition → Procurement/Receipt → Issue to Site → Consume on Site / Return to Warehouse / Wastage-Scrap → Valuation/Cost traceability.

## Commercial lifecycle
BOQ → Budget → Work/Execution → Variation Orders / Revisions → Progress Billing → Invoice → Completion.

## Quality lifecycle
Quality Check → Result/Evidence → NCR when nonconforming → CAPA → Verification → Closure.

## Revision governance
Original baseline remains historical. New BOQ, Budget, or Schedule Baseline changes are recorded as revisions with a reason and approval control rather than silently overwriting the baseline.
