# Reporting Guide

## Report Center
The application uses a single **Construction → Reports** entry point. The user selects the required report type and output format instead of navigating through a large tree of report-specific menus.

## Recommended procedure
1. Open Reports.
2. Select the report type.
3. Apply Project and date filters when applicable.
4. Decide whether archived records should be included.
5. Choose PDF or Excel.
6. Generate the report.

## Report governance
Use reports as read-oriented outputs. Correct the source construction record rather than editing exported files and treating the export as the system of record.
