# Transaction Tracker

- **المسار والإصدار:** `odoo19/transaction_tracker` — Odoo 19
- **إصدار الحزمة:** `1.0.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Track all user transactions across every Odoo module

## الغرض والنطاق

Track all user transactions across every Odoo module

هذا الوصف مرتبط بملفات الموديول في هذه النسخة. يتضمن المصدر 8 ملف Python و8 ملف XML و1 ملف JavaScript/TypeScript.
