# Direct Print Auto

- **المسار والإصدار:** `odoo19/direct_print_auto` — Odoo 19
- **إصدار الحزمة:** `19.0.1.0.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Auto-print invoices, SOs, delivery slips and POs to the browser's print dialog when confirmed, plus a manual Direct Print button on each form.

## الغرض والنطاق

Auto-print invoices, SOs, delivery slips and POs to the browser's print dialog when confirmed, plus a manual Direct Print button on each form.

هذا الوصف مرتبط بملفات الموديول في هذه النسخة. يتضمن المصدر 12 ملف Python و9 ملف XML و1 ملف JavaScript/TypeScript.

## ملفات التثبيت

`base`, `web`, `sale_management`, `account`, `stock`, `purchase`
