# Prevent Negative Stock

> Prevents negative stock quantities by rejecting any stock move that would
> result in a negative quantity. NO exceptions — even managers cannot bypass.

## Features
- ✅ Rejects ALL moves that would cause negative stock
- ✅ Applies to ALL stock types (delivery, internal, MRP)
- ✅ NO exceptions — hard business rule
- ✅ Creates alert log entry for every rejected attempt
- ✅ Sends email notification to warehouse manager

## Installation
1. Copy to Odoo addons path
2. Update Apps List
3. Install "Prevent Negative Stock"
