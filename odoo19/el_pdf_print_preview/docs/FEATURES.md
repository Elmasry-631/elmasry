# PDF Print Preview

- **المسار والإصدار:** `odoo19/el_pdf_print_preview` — Odoo 19
- **إصدار الحزمة:** `19.0.1.1.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Preview PDF reports in-browser before printing — no download needed

## الوظائف الظاهرة في المصدر

- ملخص الوظيفة في manifest: Preview PDF reports in-browser before printing — no download needed
- نموذج Odoo: IrHttp: model _inherit
- نموذج Odoo: ResUsers: model _inherit
- نموذج Odoo: IrActionsReport: model _inherit
- نقطة HTTP: '/pdf_print_preview/get_report_name' (auth=user)

## التكوين والإضافات

الاعتماديات المعلنة: `base`, `web`
