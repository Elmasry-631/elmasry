# PDF Print Preview

- **المسار والإصدار:** `odoo19/el_pdf_print_preview` — Odoo 19
- **إصدار الحزمة:** `19.0.1.1.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Preview PDF reports in-browser before printing — no download needed

## الغرض والنطاق

Preview PDF reports in-browser before printing — no download needed

هذا الوصف مرتبط بملفات الموديول في هذه النسخة. يتضمن المصدر 10 ملف Python و4 ملف XML و7 ملف JavaScript/TypeScript.

`base`, `web`
