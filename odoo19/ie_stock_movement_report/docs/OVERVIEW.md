# Stock Movement Report

- **المسار والإصدار:** `odoo19/ie_stock_movement_report` — Odoo 19
- **إصدار الحزمة:** `19.0.1.0.0`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** PDF report of inventory movements with opening/closing balance and running value.

PDF report of inventory movements with opening/closing balance and running value.

هذا الوصف مرتبط بملفات الموديول في هذه النسخة. يتضمن المصدر 10 ملف Python و4 ملف XML و0 ملف JavaScript/TypeScript.
