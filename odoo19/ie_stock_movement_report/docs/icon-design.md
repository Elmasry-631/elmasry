# Icon Design — ie_stock_movement_report

## Visual description

- **Background:** Solid purple (#7C3AED) — Odoo's Inventory category color
- **Foreground:** White box (60,70 to 130,140) representing a stock item
- **Arrows:** Two white triangles representing IN/OUT movement
  - Right arrow at (150-200, 90-120) — outgoing
  - Left arrow at (100-150, 160-190) — incoming

## Color choice rationale

- **Purple** is Odoo's standard Inventory category color (per skill's
  icon brief collection rules)
- **White** foreground provides maximum contrast on purple background
- No text in icon — keeps it readable at 16x16 size in Odoo app list
