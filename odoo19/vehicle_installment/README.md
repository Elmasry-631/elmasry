# Vehicle Installment Management Module

## نظرة عامة
موديول إدارة أقساط السيارات في Odoo - مصمم لحساب أقساط السيارات مع معالجة الكسور العشرية بشكل دقيق.

## المميزات
- ربط مباشر مع موديول Fleet (إدارة المركبات)
- حساب تلقائي للفائدة والمبلغ الإجمالي
- معالجة ذكية للكسور العشرية في الأقساط
- جدول زمني تلقائي للدفعات الشهرية
- نظام الموافقات والصلاحيات
- تتبع حالة كل قسط

## كيفية الحساب

### مثال عملي:
- **سعر السيارة**: 20,000 جنيه
- **نسبة الفائدة**: 20%
- **القسط الشهري**: 1,800 جنيه

### خطوات الحساب:

1. **حساب المبلغ الإجمالي**:
   ```
   المبلغ الإجمالي = سعر السيارة + (سعر السيارة × نسبة الفائدة ÷ 100)
   المبلغ الإجمالي = 20,000 + (20,000 × 20 ÷ 100)
   المبلغ الإجمالي = 20,000 + 4,000 = 24,000 جنيه
   ```

2. **حساب عدد الأشهر**:
   ```
   عدد الأشهر = المبلغ الإجمالي ÷ القسط الشهري
   عدد الأشهر = 24,000 ÷ 1,800 = 13.333333 شهر
   ```

3. **فصل الجزء الصحيح عن الكسور**:
   ```
   الأشهر الكاملة = 13 شهر (الجزء الصحيح)
   الجزء الكسري = 0.333333
   ```

4. **حساب القسط الأخير**:
   ```
   القسط الأخير = الجزء الكسري × القسط الشهري
   القسط الأخير = 0.333333 × 1,800 = 599.9994 جنيه
   ```

### النتيجة:
- **13 قسط** بقيمة **1,800 جنيه** لكل قسط
- **قسط أخير** بقيمة **599.9994 جنيه**
- **إجمالي الأقساط**: 14 قسط

## الحقول الرئيسية

### معلومات أساسية:
- **Vehicle (السيارة)**: ربط مع سيارة من موديول Fleet
- **Employee (الموظف)**: الموظف المسؤول عن القسط
- **Date (التاريخ)**: تاريخ بدء التقسيط

### معلومات مالية:
- **Vehicle Price (سعر السيارة)**: السعر الأساسي للسيارة
- **Rate Percentage (نسبة الفائدة)**: النسبة المئوية للفائدة
- **Monthly Payment (القسط الشهري)**: قيمة القسط الشهري المطلوب

### حقول محسوبة تلقائيًا:
- **Total Amount (المبلغ الإجمالي)**: السعر + الفائدة
- **Calculated Months (عدد الأشهر المحسوب)**: العدد الكامل مع الكسور
- **Full Payment Months (الأشهر الكاملة)**: عدد الأشهر بالأقساط الكاملة
- **Last Payment Amount (قيمة القسط الأخير)**: قيمة القسط الأخير المحسوب من الكسور

## سير العمل (Workflow)

1. **Draft (مسودة)**: إنشاء سجل جديد وإدخال البيانات
2. **Waiting (قيد الانتظار)**: بعد حساب الأقساط، ينتقل للمراجعة
3. **Approved (موافق عليه)**: بعد الموافقة من المدير
4. **Rejected (مرفوض)**: إذا تم رفض الطلب
5. **Paid (مدفوع)**: بعد سداد كل الأقساط

## الصلاحيات

### User (مستخدم عادي):
- عرض أقساطه الخاصة فقط
- عرض أقساط موظفيه (إن كان مدير)
- لا يمكنه التعديل أو الحذف بعد الموافقة

### Administrator (مدير):
- عرض وتعديل كل الأقساط
- الموافقة أو الرفض
- حساب الأقساط
- حذف السجلات غير الموافق عليها

## التثبيت

1. انسخ المجلد `vehicle_installment` إلى مجلد addons
2. أعد تشغيل خدمة Odoo
3. قم بتحديث قائمة التطبيقات (Apps)
4. ابحث عن "Vehicle Installment Management"
5. اضغط Install

## المتطلبات
- Odoo 15.0 أو أحدث
- موديول Fleet (fleet)
- موديول HR (hr)
- موديول Mail (mail)

## ملاحظات هامة

1. **التواريخ**: تبدأ الأقساط من يوم 25 من كل شهر
2. **الحذف**: يمكن حذف السجلات في حالة Draft أو Rejected فقط
3. **التعديل**: بعد الموافقة، فقط المدير يمكنه التعديل
4. **الشركة**: يرى كل مستخدم أقساط شركته فقط
