# أمثلة على حسابات أقساط السيارات

## مثال 1: حساب بسيط بدون كسور

### المدخلات:
- سعر السيارة: 18,000 جنيه
- نسبة الفائدة: 0%
- القسط الشهري: 1,800 جنيه

### الحسابات:
```
المبلغ الإجمالي = 18,000 + (18,000 × 0 ÷ 100) = 18,000 جنيه
عدد الأشهر = 18,000 ÷ 1,800 = 10.0 شهر
الأشهر الكاملة = 10 أشهر
القسط الأخير = 1,800 جنيه (لا توجد كسور)
```

### النتيجة:
- **10 أقساط** كل قسط **1,800 جنيه**

---

## مثال 2: حساب مع كسور (المثال الأصلي)

### المدخلات:
- سعر السيارة: 20,000 جنيه
- نسبة الفائدة: 20%
- القسط الشهري: 1,800 جنيه

### الحسابات:
```
المبلغ الإجمالي = 20,000 + (20,000 × 20 ÷ 100)
المبلغ الإجمالي = 20,000 + 4,000 = 24,000 جنيه

عدد الأشهر = 24,000 ÷ 1,800 = 13.333333 شهر

الأشهر الكاملة = 13 شهر
الجزء الكسري = 0.333333

القسط الأخير = 0.333333 × 1,800 = 599.9994 جنيه
```

### النتيجة:
- **13 قسط** كل قسط **1,800 جنيه**
- **قسط أخير واحد** بقيمة **599.9994 جنيه**
- **إجمالي الأقساط**: 14 قسط

## مثال 5: كسور كبيرة

### المدخلات:
- سعر السيارة: 25,000 جنيه
- نسبة الفائدة: 25%
- القسط الشهري: 2,000 جنيه

### الحسابات:
```
المبلغ الإجمالي = 25,000 + (25,000 × 25 ÷ 100)
المبلغ الإجمالي = 25,000 + 6,250 = 31,250 جنيه

عدد الأشهر = 31,250 ÷ 2,000 = 15.625 شهر

الأشهر الكاملة = 15 شهر
الجزء الكسري = 0.625

القسط الأخير = 0.625 × 2,000 = 1,250 جنيه
```

### النتيجة:
- **15 قسط** كل قسط **2,000 جنيه**
- **قسط أخير واحد** بقيمة **1,250 جنيه**
- **إجمالي الأقساط**: 16 قسط

## ملاحظات مهمة:

1. **الحسابات في النظام تلقائية**: بمجرد إدخال البيانات، يحسب النظام كل شيء تلقائياً
2. **الدقة**: النظام يستخدم `math.floor()` لفصل الجزء الصحيح بدقة
3. **القسط الأخير**: يُحسب من الجزء الكسري × القسط الشهري
4. **التحقق**: يمكن التحقق من الحسابات بجمع كل الأقساط والتأكد من مساواتها للمبلغ الإجمالي

---

## صيغة الحساب الرياضية:

```
المبلغ الإجمالي = P × (1 + R/100)

حيث:
P = سعر السيارة (Vehicle Price)
R = نسبة الفائدة (Rate Percentage)

عدد الأشهر = المبلغ الإجمالي ÷ القسط الشهري

الأشهر الكاملة = floor(عدد الأشهر)

القسط الأخير = (عدد الأشهر - الأشهر الكاملة) × القسط الشهري
```
