# تحليل شامل لموديول `inventory_report_generator` (Odoo 19)

---

## 📌 اسم الموديول ووصفه

**الاسم:** Inventory All In One Report Generator

**المُعرف التقني:** `inventory_report_generator`

**المطور:** Cybrosys Techno Solutions

**الفئة:** الإنتاجية (Productivity)

### الوصف العام
هذا الموديول يوفر مولّد تقارير مخزون ديناميكي شامل (All-In-One). يتيح للمستخدمين إنشاء تقارير مخزون بأنواع متعددة مع إمكانية التصفية حسب نطاق تاريخي، ويدعم التصدير بصيغتي PDF و XLSX. يستخدم واجهة OWL.js الحديثة مع Client Action.

## 🏗️ الموديلات (Models)

### 1️⃣ `dynamic.inventory.report`

| الحقل | النوع | الوصف |
|---|---|---|
| `purchase_report` | `Char` | اسم التقرير |
| `date_from` | `Datetime` | تاريخ البداية |
| `date_to` | `Datetime` | تاريخ النهاية |
| `report_type` | `Selection` | نوع التقرير |

#### أنواع التقارير المتاحة:

| القيمة | الاسم |
|---|---|
| `report_by_transfers` | Report By Transfers (التقرير بالتحويلات) |
| `report_by_categories` | Report By Categories (التقرير بالفئات) |
| `report_by_warehouse` | Report By Warehouse (التقرير بالمستودعات) |
| `report_by_location` | Report By Location (التقرير بالمواقع) |

#### الطرق الرئيسية:

| الطريقة | الوصف |
|---|---|
| `inventory_report()` | الطريقة الرئيسية — تُرجع بيانات التقرير للواجهة الأمامية |
| `get_filter()` | يُرجع قاموس الفلاتر |
| `_get_report_sub_lines()` | جلب البيانات باستخدام استعلامات SQL المباشرة حسب نوع التقرير |
| `_get_report_values()` | تجميع البيانات النهائية |
| `get_inventory_xlsx_report()` | توليد ملف XLSX باستخدام xlsxwriter |

## 🖥️ واجهة المتصفح (Frontend - OWL.js)

### المكون: `InventoryReport`
- واجهة حديثة بدون إعادة تحميل الصفحة
- فلاتر تاريخ ديناميكية
- جدول ديناميكي لعرض النتائج
- زر "Print (PDF)" و "Export (XLSX)"
- في تقرير التحويلات: يمكن النقر على المرجع لفتح أمر التحويل

---

## 🖨️ التقارير (Reports)

### تقرير PDF — `InventoryPDFReport`
- تقرير QWeb-PDF مع قوالب مختلفة حسب نوع التقرير
- **التحويلات**: المرجع، التاريخ، المصدر، الشركة، العنوان، الحالة
- **الفئات**: الفئة، المنتج، التاريخ، التكلفة، الموقع، الكمية
- **المستودعات**: المستودع، التاريخ، الشركة، الموقع، المسار
- **المواقع**: الموقع، النوع، التاريخ، الشركة

---

## 🌐 وحدات التحكم (Controllers)

- **نقطة النهاية:** `/inventory_dynamic_xlsx_reports` (HTTP POST)
- يُرجع ملف XLSX كاستجابة HTTP
- يتطلب تسجيل دخول

---

## 🚀 طريقة الاستخدام

1. من قائمة **المخزون → التقارير → All In One Inventory Report**
2. اختيار نوع التقرير والنطاق الزمني
3. الضغط على **Apply** لتحديث البيانات
4. **تصدير PDF** أو **XLSX**

## 🔧 ملاحظات تقنية

### ✅ نقاط القوة:
- واجهة OWL.js حديثة وسريعة
- أنواع تقارير متعددة في مكان واحد
- تصدير مزدوج (PDF + XLSX)
- فلاتر تاريخ ديناميكية

### ⚠️ القصور:
- ⛔️ **ثغرة أمنية SQL Injection:** الاستعلامات تستخدم `"%s" % value` دون معلمات آمنة
- كود ميت (Dead Code) في `_get_report_total_value`
- لا يوجد بحث أو ترقيم صفحات
- صلاحيات أمنية واسعة جداً
