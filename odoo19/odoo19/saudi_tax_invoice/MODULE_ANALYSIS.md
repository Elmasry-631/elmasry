# تحليل شامل لموديول `saudi_tax_invoice` (Odoo 19)

---

## 📌 اسم الموديول ووصفه

**الاسم:** Saudi Tax Invoice

**المُعرف التقني:** `saudi_tax_invoice`

**المطور:** Ibrahim Elmasry

**الفئة:** المحاسبة (Accounting)

### الوصف العام
قالب تقرير PDF مخصص للفاتورة الضريبية السعودية. يُضيف زر طباعة جديد في نموذج الفاتورة يُنتج تقرير PDF بتصميم RTL (من اليمين لليسار) يتضمن بيانات الشركة والعميل والبنك ورمز QR.

## 🖨️ التقارير (Reports)

### تقرير PDF — `action_report_invoice_saudi`

#### تنسيق الورق (Paper Format):
- **الحجم:** A4
- **الاتجاه:** Portrait (طولي)
- **الهوامش:** 10mm يمين/يسار، 10mm علوي، 20mm سفلي

#### أقسام القالب:

**القسم 1: رأس الفاتورة**
- شعار الشركة
- اسم الشركة
- الرقم الضريبي (VAT)
- السجل التجاري

**القسم 2: بيانات العميل والفاتورة**
- **بيانات العميل:** الاسم، الرقم الضريبي، العنوان، الهاتف
- **بيانات الفاتورة:** الرقم، التاريخ، تاريخ الاستحقاق، المصدر

**القسم 3: جدول بنود الفاتورة**

| العمود | المصدر |
|---|---|
| تسلسل | `line.sequence` |
| الوصف | `line.name` |
| الكمية | `line.quantity` |
| سعر الوحدة | `line.price_unit` |
| الخصم | `line.discount` |
| الضريبة | `line.tax_ids[0].amount` |
| المبلغ قبل الضريبة | `line.price_subtotal` |
| مبلغ الضريبة | `price_total - price_subtotal` |
| المجموع | `line.price_total` |

**القسم 4: التذييل بثلاثة أعمدة**
- **الأيسر**: معلومات البنك
- **الوسط**: رمز QR
- **الأيمن**: المجاميع (الإجمالي، الضريبة، المجموع الكلي)

---

## 🚀 طريقة الاستخدام

1. افتح أي فاتورة في نموذج `account.move`
2. اضغط على زر **"Print"** في القائمة
3. اختر **"Saudi Tax Invoice"**
4. سيتم تنزيل تقرير PDF

## 🔧 ملاحظات تقنية

### ✅ نقاط القوة:
- تصميم RTL جيد
- تنسيق PDF احترافي
- زر طباعة مدمج تلقائياً عبر `binding_model_id`

### ⚠️ القصور والمشاكل:
- ⛔️ **بيانات البنك ثابتة (hardcoded)**: اسم البنك والحساب والآيبان مكتوبة مباشرة في الكود — لا يمكن تغييرها من الواجهة
- ⛔️ **رمز QR ثابت**: صورة base64 مدمجة — ليست QR ديناميكي وفق متطلبات ZATCA
- ⛔️ **لا يتوافق مع فاتورة ZATCA**: الفاتورة الضريبية السعودية تتطلب XML مُوحد وTLV encoding
- تاريخ التوريد مكرر (يستخدم `invoice_date_due` مرتين)
- التذييل قد يظهر خارج الصفحة (`bottom: -1200px`)
- الضريبة تُعرض من الضريبة الأولى فقط — لا يدعم ضرائب متعددة
- ملف CSS موجود لكن غير مرتبط بالتقرير
- اسم القالب `stock_movement_report_template` غير منطقي لفاتورة ضريبية
