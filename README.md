# Odoo Modules Inventory

الملف ده بيجمع الموديولات الموجودة في الريبوزتري ويصنفها حسب إصدار Odoo: `18` و `19`، مع وصف مختصر لوظيفة كل موديول.

## Odoo 18 Modules

| الموديول | بيعمل إيه |
| --- | --- |
| `access_right_product_partner` | يضيف/ينظم صلاحيات مرتبطة بالمنتجات وجهات الاتصال/الشركاء. |
| `account_invoice_fixed_discount` | يتيح إضافة خصم بقيمة ثابتة على فواتير العملاء أو الموردين. |
| `account_move_base_import` | يوفر أساس لاستيراد قيود اليومية/الحركات المحاسبية. |
| `account_reconcile_model_oca` | يضيف منطق نماذج المطابقة المحاسبية الخاص بـ OCA/Community. |
| `account_reconcile_oca` | يضيف أدوات ومشاهد مطابقة الحسابات وكشوف البنك في Odoo Community. |
| `account_statement_base` | موديول أساسي لدعم كشوف الحسابات البنكية. |
| `activity_dashboard_mngmnt` | لوحة متابعة لإدارة الأنشطة والمهام بشكل مركزي. |
| `advanced_chatter_view` | يحسن طريقة عرض الـ Chatter داخل النماذج. |
| `base_account_budget` | يضيف إدارة الميزانيات لإصدار Odoo 18 Community. |
| `base_accounting_kit` | حزمة محاسبة كاملة تشمل تقارير مالية وأصول ومتابعات وميزات محاسبية. |
| `bf_dashboard_balance` | يضيف بيانات/حقول أرصدة للدفاتر أو اليوميات لاستخدامها في الداشبورد. |
| `bi_health_care_center_management` | إدارة عمليات مراكز الرعاية الصحية. |
| `bi_so_product_quantity_limit` | يضع حدود دنيا/قصوى لكميات المنتجات داخل أوامر البيع. |
| `bi_sport_center_management` | إدارة مراكز الرياضة/اللياقة والاشتراكات والحجوزات والمدربين. |
| `cup_is_customer_is_vendor` | يضيف حقول لتحديد الشريك كعميل و/أو مورد. |
| `dynamic_accounts_report` | تقارير محاسبية ومالية ديناميكية لإصدار Odoo 18. |
| `inventory_report_generator` | مولد تقارير مخزون ديناميكية متعددة الاستخدامات. |
| `inventory_stock_dashboard_odoo` | داشبورد تفصيلي لمتابعة المخزون. |
| `invoice_stock_move` | ينشئ عمليات مخزون/استلام أو تسليم من فواتير العملاء أو الموردين. |
| `meno` | تعديلات خاصة على إصدار Odoo 18. |
| `pdf_print_preview` | معاينة وطباعة تقارير PDF من المتصفح بدل التحميل المباشر. |
| `prt_report_attachment_preview` | فتح تقارير ومرفقات PDF في المتصفح بدلاً من تنزيلها. |
| `sale_order_automation` | أتمتة دورة أمر البيع مثل التأكيد وإنشاء/اعتماد الفاتورة وتحويل التسليم. |
| `sale_order_contract` | إنشاء عقود تلقائياً من أوامر البيع. |
| `sale_order_contract_terms` | تقرير أمر بيع منفصل بشروط تعاقد ثنائية اللغة عربي/إنجليزي. |
| `sale_report_advanced` | تقارير مبيعات متقدمة. |
| `sale_stock_restrict` | يمنع أو يقيد بيع المنتجات غير المتوفرة بالمخزون. |
| `sales_credit_limit` | إدارة حد ائتمان العميل مع تنبيهات أو منع عند تجاوز الحد/المستحقات. |
| `stock_last_purchase_price` | يضيف طريقة تكلفة تعتمد على آخر سعر شراء. |
| `stock_move_invoice` | إنشاء فاتورة من عملية استلام/تسليم المخزون. |
| `total_payable_receivable` | يعرض إجمالي المستحقات المدينة والدائنة على نموذج الشريك. |
| `trad_paints_delivery_report` | تقارير/تعديلات تسليم خاصة ببيئة Trade Paints. |
| `trade_paints_adjustment` | تعديلات خاصة بعمليات Trade Paints. |
| `trade_paints_features` | مجموعة خصائص مخصصة لـ Trade Paints تشمل البيع والشراء والمخزون والتقارير. |
| `trade_paints_inventory` | تخصيصات مخزون وتقارير وتحويلات خاصة بـ Trade Paints. |
| `tradepaints_saleorder_report` | تقرير مخصص لأوامر البيع الخاصة بـ Trade Paints. |
| `transfer_wizard` | معالج لنقل/تحويل المخزون أو العمليات المرتبطة به. |
| `view_any_model` | يتيح عرض سجلات أي موديل يتم اختياره. |
| `web_chatter_position` | يضيف خيار تغيير مكان الـ Chatter في الواجهة. |
| `web_responsive` | يحسن واجهة Odoo لتكون أكثر استجابة وملاءمة للأجهزة المختلفة. |
| `wm_purchase_global_discount` | يضيف خصم إجمالي على أوامر الشراء مشابه لخصم أوامر البيع. |
