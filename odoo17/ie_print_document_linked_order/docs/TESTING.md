# IE Print Document Linked Order

- **المسار والإصدار:** `odoo17/ie_print_document_linked_order` — Odoo 17
- **إصدار الحزمة:** `0.1`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Show all product attachments directly from Quotation.

## الاختبارات المرفقة

- لا يحتوي الموديول على مجلد `tests/`؛ لذلك لا توجد اختبارات Odoo مرفقة.

## تشغيل اختبارات Odoo

`./odoo-bin -d <test_database> -i ie_print_document_linked_order --test-enable --stop-after-init`

## فحوص المصدر

- تحقق من أن ملفات Python قابلة للتحليل وأن XML صالح.
- اختبر التثبيت على Odoo 17 مع dependencies والطبعة نفسها.
- لا تعتبر وجود ملفات tests دليلًا على نجاح تشغيلها؛ سجل النتيجة والبيئة عند التنفيذ.
