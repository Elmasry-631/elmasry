# IE Print Document Linked Order

- **المسار والإصدار:** `odoo17/ie_print_document_linked_order` — Odoo 17
- **إصدار الحزمة:** `0.1`
- **الترخيص المعلن:** `LGPL-3`
- **الملخص المعلن:** Show all product attachments directly from Quotation.

## المتطلبات

- Odoo 17 متوافق مع هذا المجلد.
- الإضافات: `base`, `sale`
- الترخيص المعلن: `LGPL-3`. راجع ملف `LICENSE` وأي إشعار حقوق مرفق قبل إعادة التوزيع.

## التثبيت

1. أضف `odoo17` إلى `addons_path` في بيئة Odoo.
2. تحقق أن كل dependency متاح في إصدار Odoo والطبعة المستهدفين.
3. حدّث قائمة التطبيقات ثم ثبّت `ie_print_document_linked_order` من Apps، أو شغّل: `./odoo-bin -d <database> -i ie_print_document_linked_order --stop-after-init`.
4. افتح الإعدادات/القوائم المذكورة في [CONFIGURATION.md](CONFIGURATION.md) واختبرها بمستخدم وصلاحيات مماثلة للإنتاج.

لا تنفذ التثبيت أو الترقية على قاعدة إنتاج قبل نسخة احتياطية ومراجعة أثر hooks وعمليات البيانات.
